# CallQuits 0.1.1

More reliable monitoring, clearer Activity messages, and easier permission recovery. This is the first Developer ID signed and notarized CallQuits release.

## Highlights

- **Recover monitoring:** Use **Retry monitoring** when CallQuits has Accessibility access but cannot watch close buttons. Failed setup is reported accurately, with permission help; intentional pauses stay paused.
- **Clearer Activity:** Verified close attempts explain why a quit was stopped, such as remaining windows, a sheet, changed windows, unreliable Accessibility data, or expiry.
- **Accurate settings status:** Launch-at-login status clears stale approval and error messages. Manual and automatic Accessibility refreshes report the same meaningful transitions.
- **Less unnecessary Accessibility work:** Excluded and ineligible apps are rejected before hit testing. Event ownership and final safety checks still guard both quit paths.

Confirmation delays and normal close/save behavior are unchanged. Protected apps, exclusions, minimized windows, and windows on other Spaces remain covered. Force quit stays opt-in and Shift-click only, with an unsaved-work warning.

## Download & install

**Apple silicon (arm64) · macOS 14 or later · Build 2**

Developer ID signed, notarized by Apple, and shipped with a stapled notarization ticket.

[Download CallQuits 0.1.1](https://github.com/Mxlted/CallQuits/releases/download/v0.1.1/CallQuits-0.1.1-macos-arm64.zip) · [SHA-256 checksum](https://github.com/Mxlted/CallQuits/releases/download/v0.1.1/SHA256SUMS.txt)

1. Quit your existing CallQuits copy, extract the ZIP, and move `CallQuits.app` to **Applications**.
2. Open it and enable **System Settings → Privacy & Security → Accessibility**.
3. Check that CallQuits says **Watching close buttons**. Launch at login may need separate Login Items approval.

**Upgrading from v0.1.0?** The signing identity changed. If Accessibility access stops working, quit CallQuits, remove its old Accessibility entry, add the current app from Applications, enable it, and relaunch. See [installation and permission help](https://github.com/Mxlted/CallQuits/blob/v0.1.1/docs/HELP.md).

This download is Apple silicon only. macOS 14 and Intel runtime behavior, and installation on a separate Mac/account, remain unverified. Intel users can try a source build.

<summary>Technical details, validation & known limitations</summary>

- **Monitoring and Activity:** Failed event-tap creation or re-enabling is reflected in status. Paused and disabled states are preserved. Cancellation messages describe observed state without claiming that a user canceled a dialog. Activity remains bounded and session-only, without window titles, document names, or click histories.
- **Maintenance:** Validation, version metadata, and release preparation are simpler to maintain. CI retains one macOS validation job; downloadable development artifacts are produced only on manual dispatch.
- **Release verification:** The Developer ID release build, strict signature checks, Apple notarization (Accepted, no reported issues), stapled-ticket validation, and macOS pre-distribution checks passed. Fresh ZIP extraction preserved executable permissions, signature, and ticket; the final checksum verified.
- **Automated coverage:** All **50 XCTest cases passed**, covering event identity, application eligibility, close confirmation/cancellation, settings status, and simulated monitoring recovery. They do not exercise physical clicks, the event tap, or Accessibility observers.
- **Remaining validation:** The full live fixture matrix remains incomplete, including save cancellation, replacement windows, minimized windows, other Spaces, exclusions on both quit paths, and monitoring recovery. Separate-Mac/account fresh-install and upgrade permission behavior remain unverified.
- **Performance:** No click-to-quit-request, process-exit, or Dock-disappearance timings were collected. Reduced Accessibility work is an expected benefit, not a measured latency improvement. Deadline, observer, and concurrency optimizations remain deferred pending measurements.
- **Compatibility limits:** Missing Accessibility metadata, unsupported window notifications, very fast clicks, or unresponsive apps can prevent automatic quit. CallQuits skips uncertain attempts. Keyboard, menu, and programmatic closes do not trigger it.

See the [testing record](https://github.com/Mxlted/CallQuits/blob/v0.1.1/docs/TESTING.md) for coverage and observed results. Use the checksum file from this release to verify its ZIP.
