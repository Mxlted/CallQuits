# CallQuits 0.1.0

The first development release of CallQuits, a small menu bar utility that can quit an app after you click its red close button.

## Highlights

- **Quit on close:** A verified red-button click requests a graceful quit after the app's last window closes. An optional mode applies after any window closes.
- **Simple controls:** Pause CallQuits, edit app exclusions, and enable launch at login. Finder, system processes, and CallQuits stay protected.
- **Optional force quit:** Shift-click force quit is disabled by default and requires an unsaved-work warning. Normal close never escalates to force quit.
- **Original icon:** A coral close button and power mark on a dark window, also used in settings.

## Download & install

**Apple silicon (arm64) · macOS 14 or later · Build 1**

> **Development build — ad hoc signed, not notarized.** This release has no verified Developer ID or stapled notarization ticket. Gatekeeper may block first launch.

[Download CallQuits 0.1.0](https://github.com/Mxlted/CallQuits/releases/download/v0.1.0/CallQuits-0.1.0-macos-arm64.zip) · [SHA-256 checksum](https://github.com/Mxlted/CallQuits/releases/download/v0.1.0/SHA256SUMS.txt)

1. Extract the ZIP and move `CallQuits.app` to **Applications**.
2. Open it and enable **System Settings → Privacy & Security → Accessibility**. Relaunch if needed.
3. If replacing an ad hoc build leaves a stale Accessibility entry, remove the old entry and add the current app again. Launch at login may need separate Login Items approval.

This download is Apple silicon only. macOS 14 and Intel runtime behavior were not tested for this artifact. Intel users can try a source build.

<summary>Technical details, validation & known limitations</summary>

- **Automated coverage:** All **40 Swift policy tests passed**, covering event identity, click/modifier matching, protected apps, close cancellation, sheets, replacement windows, and unreadable snapshots.
- **Build verification:** The release build, whitespace checks, bundle metadata, and strict code-signature verification passed. ZIP extraction preserved executable permissions, app contents, and signature. No valid Apple signing identity was available for this build.
- **Test environment:** Apple silicon, macOS 27.0.1, and Swift 6.4.
- **Remaining validation:** Live physical-click, save-dialog, multiple-window, minimized-window, Spaces, and force-quit checks remain incomplete. Policy tests do not establish full Accessibility integration coverage or Dock-disappearance timing.
- **Compatibility limits:** Missing Accessibility metadata, unsupported window notifications, very fast clicks, or unresponsive apps can prevent automatic quit. Keyboard, menu, and programmatic closes do not trigger it.

Use the checksum file from this release to verify its ZIP.
