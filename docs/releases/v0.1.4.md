# CallQuits 0.1.4

More reliable closing for blank, untitled editor windows, safer handling of interrupted close attempts, and a new drag-to-Applications DMG download.

## Highlights

- **Empty-editor close fix:** Captures the original window list before completing close-button verification, so a blank document closing immediately afterward no longer discards a verified click. This addresses a race found while investigating CotEditor's empty Untitled window and relevant to the reported TextEdit behavior.
- **Fewer unrelated interruptions:** Another application hiding no longer cancels a valid close attempt in the target app.
- **Safer interruption handling:** Right-clicks and auxiliary mouse presses cancel pending attempts. The original application identity is checked through the final quit request, so a restarted process cannot inherit an old attempt.
- **DMG downloads from this release onward:** Open the disk image and drag CallQuits to its Applications shortcut.

Save dialogs, replacements, minimized windows, exclusions, and explicit close-button verification remain protected. The confirmation intervals are unchanged. Force quit remains opt-in and Shift-click only.

## Download & install

**Apple silicon (arm64) · macOS 14 or later · Build 5**

The app and DMG are Developer ID signed, notarized by Apple, and carry stapled notarization tickets.

[Download CallQuits 0.1.4 DMG](https://github.com/Mxlted/CallQuits/releases/download/v0.1.4/CallQuits-0.1.4-macos-arm64.dmg) · [SHA-256 checksum](https://github.com/Mxlted/CallQuits/releases/download/v0.1.4/SHA256SUMS.txt)

1. Quit your existing CallQuits copy and open the DMG.
2. Drag `CallQuits.app` to **Applications**, replace the old copy if prompted, and eject the disk image.
3. Open CallQuits from Applications. Enable **System Settings → Privacy & Security → Accessibility** and check for **Watching close buttons**. Launch at login may need separate Login Items approval.

**Upgrading from v0.1.0?** The signing identity changed. If Accessibility access stops working, quit CallQuits, remove its old Accessibility entry, add the current app from Applications, enable it, and relaunch. See [installation and permission help](https://github.com/Mxlted/CallQuits/blob/v0.1.4/docs/HELP.md).

<summary>Validation & known limitations</summary>

- All 95 debug XCTest cases passed. Coverage includes exact event identity, close-button proof, malformed or unavailable Accessibility values, cancellation, window membership, and application lifecycle checks.
- A disposable native `NSDocument` fixture reproduced the empty-document capture race: the prior adapter discarded eight of eight attempts; the updated adapter accepted eight of eight with normal confirmation. A dirty document's actual save sheet, remaining document, and replacement document all blocked quitting. These measurements are distinct from physical mouse input, cross-process observer delivery, actual application exit, and Dock disappearance.
- The final Developer ID build, strict signature checks, both Apple notarizations (Accepted, no reported issues), and both stapled tickets passed validation. The final DMG's checksum and integrity verified; a fresh copy of its app retained executable permissions, signature, and ticket. `syspolicy_check distribution` passed. `spctl` reported a security-disabled override, so default Gatekeeper enforcement was not tested.
- Very fast clicks that destroy the control before Accessibility can identify it still safely skip automatic quit. Startup file choosers and modal dialogs are not treated as normal editor windows. Native tabs can conservatively cancel when closing one reveals another window identity.
- Physical verification with CotEditor and TextEdit, the full live fixture matrix, macOS 14/Intel runtime, and fresh-install/upgrade checks on a separate Mac/account remain incomplete. This download contains only Apple silicon code; notarization and a deployment target do not establish those runtime results.
- Activity remains bounded and session-only, without document names, window titles, or click histories.
